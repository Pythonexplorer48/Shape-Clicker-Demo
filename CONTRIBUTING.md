# Contributing to Shape Clicker

Hi! I am mainly making this game on my own, but I am happy to hear your ideas!

## How to Help
* **Ideas:** If you have a Pull Request (PR), please explain your idea clearly first. 
* **Issues:** If you find a bug or something is broken, please open an "Issue" and tell me exactly what happened. I accept and appreciate all bug reports!
* **Don't Mess Around:** Please only submit serious suggestions. I put a lot of work into this, so let's keep the code clean and the ideas helpful.

Thank you for helping me make Shape Clicker better!
