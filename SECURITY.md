# Security Policy

## Reporting a Bug
Since this is a personal project, I want to make sure it stays safe and efficient for everyone.

If you find a security issue or a major exploit:
1. Please **do not** post it publicly in the "Issues" tab right away.
2. Send me a private message or a detailed Pull Request.
3. I will work on a fix as soon as I can!

I am committed to keeping Shape Clicker low-RAM and safe for everyone to play.
